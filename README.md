\# WONJUGA-PORTAL



Full-stack portal for WONJUGA.



\## Structure

\- CLIENT - Frontend

\- SERVER - Backend



\## How to Run

1\. git clone https://github.com/EzekielAs/WONJUGA-PORTAL.git

2\. cd SERVER \&\& npm install \&\& npm run dev

3\. cd ../CLIENT \&\& npm install \&\& npm run dev



\## Tech

React, Node.js, Express, MongoDB
